# AI Server Monitoring & Alert System

## Overview

This project is an AI-powered server monitoring system that tracks system performance metrics and detects anomalies using machine learning.

## Features

* Real-time monitoring of CPU, Memory, Disk, and Network usage
* Anomaly detection using Isolation Forest
* Alert generation for unusual system behavior
* Dashboard for visualizing system health
* Logging and monitoring history

## Tech Stack

* Python
* Flask
* Machine Learning (Scikit-learn)
* SQLite/MySQL
* HTML, CSS, JavaScript

## How it works

The system collects system metrics using Python libraries, analyzes patterns using ML models, and triggers alerts when abnormal behavior is detected.

## Future Improvements

* Email notifications for alerts
* Cloud deployment
* Grafana integration for advanced dashboards
